# Distributed Systems & Fundamentals Vault

A collection of resources I use to learn and prepare for distributed systems and data platform engineering interviews.

It covers topics like LLD, HLD, storage internals, ClickHouse, Delta Lake, Iceberg, Kafka, Flink, cloud, JVM langauages, Python , infrastructure, and other distributed systems fundamentals.

View it live: **https://codelabuk.github.io/engineering-vault/**

This is a personal reference vault, not a course. It brings together useful documentation, articles, deep-dives, and videos in one place so I can quickly find and revisit topics when preparing or learning something new.
